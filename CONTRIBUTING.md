# Contributing

Contributions are welcome when they improve the portability, clarity, validation rules, examples, or documentation of this product-import specification.

## Good contributions

- Additional schema validation rules
- Better error examples
- More complete simple/variable product samples
- WooCommerce edge cases
- Taxonomy mapping approaches that avoid duplicates
- Tests or validation utilities built around the published schema
- Documentation corrections

## Please avoid

- Committing credentials or secrets
- Adding vendor/customer personal data
- Adding proprietary Shopwice production code
- Adding keyword-stuffed links or unrelated promotional content
- Changing field meanings without documenting backward compatibility

## Pull requests

A pull request should explain:

1. What problem it solves
2. Which files or schema fields change
3. Whether existing example packages remain valid
4. Any migration consideration
